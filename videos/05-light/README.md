# 005 · How does a light bulb make light? (LED)

48 s · seamless loop · 9:16 · 60 fps · 120 BPM · cinematic pixel-3D. Build: `npm run video:light` (~6.5 min).

Three scales joined by flashes of light: hanging LED bulb (x-ray) → inside the copper wire (electrons crawl,
the push races down the wire on every beat) → inside the LED chip (electrons fall into holes, one photon = one note;
blue light + yellow phosphor = white) → back out to the bulb.

Facts: electron drift in household wire is a fraction of a mm/s (slower than a snail, ~1 mm/s); the electrical
signal travels at a large fraction of light speed; photon colour set by the energy drop (bigger = bluer);
white LEDs = blue LED + yellow phosphor; incandescent filaments run over 2,000 °C.
