# 017 · How does anesthesia switch you off?
40 s loop (16 bars), 96 BPM lo-fi / neo-soul (Rhodes, round bass, swung boom-bap, whistle hook). The music goes under
with the patient (master low-pass + half-time) and drops when the drip stops. `python3 videos/17-anesthesia/build.py`
writes `remotion/src/videos/anesthesia/anesthesia.json` + `public/videos/17-anesthesia/music.wav`.
Render: `npm run video:anesthesia` (composition `AnesthesiaVideo`).
Sources: Brown, Lydic & Schiff, NEJM 2010 (reversible coma); Purdon et al., PNAS 2013 (EEG slow waves + alpha);
Alkire et al., Science 2008 (thalamocortical connectivity).
