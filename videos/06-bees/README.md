# 006 · How do bees build perfect hexagons?

48 s · seamless loop · 9:16 · 60 fps · 120 BPM · cinematic pixel-3D. Build: `npm run video:bees` (~9 min).

Finished comb → rewind to nothing → bees hang in chains making wax → flakes from 8 wax glands → the comb grows
(every new cell is a note, on the 16th-note grid) → pixel diagrams (circles leave ~9% gaps, hexagons use ~7% less wall
than squares) → cells tilt up → honey + wax caps → back to the finished comb.

Facts: 4 pairs (8) of wax glands under the abdomen; festooning bees are the wax makers; wax is chewed soft;
hexagons: no gaps and least wall for equal-area cells (Hales, 1999); about 8 kg of honey per kg of wax (commonly
cited, estimates vary); cells tilt up a few degrees so honey doesn't drip.
