# 010 · How does a baby form?

48 s · seamless loop · 9:16 · 60 fps · **140 BPM jersey club / trap** (≈ a baby's heart rate) · true pixel-art 3D.
Build: `npm run video:baby` (~3 min).

Egg in the tube → sperm race (hat rolls) → only one gets in (impact) → 1→2→4→8→16→32 cells (the chord gains voices)
→ day-5 blastocyst → implantation → week 6 heartbeat (lub-dub kick on every beat) → growth with size comparisons
(808 hit per stage) → head down → birth → "it all started as one cell" → back to the egg (loop).
Tasteful and scientific: starts at fertilisation, nothing explicit.

Facts: ~250 million sperm set off, a few hundred reach the egg, one fertilises it; the egg ~0.1 mm (largest human
cell); cleavage divisions without growth; blastocyst ~day 5 (~100 cells), implants ~days 6–10; heartbeat from
~week 6, fetal rate 110–160 bpm; week 8 ~1.6 cm (raspberry), week 12 ~5 cm (lime), week 20 ~25 cm (banana),
week 40 ~50 cm / ~3.4 kg; most babies are head-down at birth.
