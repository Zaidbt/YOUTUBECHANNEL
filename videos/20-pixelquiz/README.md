# 020 · PIXEL QUIZ — how screens work, as a 3-level game
40 s loop (18 bars), 108 BPM electro-funk (vocal-chop riff, slap bass, clav). The viewer plays: question → 3-2-1
countdown (beeps on the beat) → one continuous zoom into the phone's pixel grid for the answer → score HUD.
`python3 videos/20-pixelquiz/build.py` writes `remotion/src/videos/pixelquiz/pixelquiz.json` +
`public/videos/20-pixelquiz/music.wav`. Render: `npm run video:pixelquiz` (composition `PixelQuizVideo`).
(Older, unrelated: `videos/09-screens`.) Unfinished experiments from the same week: `18-afterimage` (stare-at-the-dot
illusion, user: "visuel nul / meh") and `19-blink` (staring contest, peek only).
