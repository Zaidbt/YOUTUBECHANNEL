# 027 · How a 2-stroke engine works (pixel art)
40.6 s loop (22 bars), 130 BPM big beat (breakbeat, funky bass, brass stabs, organ, "ring-ding-ding" pluck riff). The
engine plays the drums: every ignition (top-dead-centre crossing) is a bang + an exhaust "ding"; slow-motion revolutions
make each bang a big hit. Crank revolutions are integers per section so the loop is seamless.
`python3 videos/27-twostroke/build.py` writes `remotion/src/videos/twostroke/twostroke.json` + `public/videos/27-twostroke/music.wav`.
Render: `npm run video:twostroke` (composition `TwoStrokeVideo`).
