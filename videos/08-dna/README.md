# 008 · How does your DNA copy itself?

48 s · seamless loop · 9:16 · 60 fps · 150 BPM · true pixel-art 3D (cell palette). Build: `npm run video:dna` (~3.5 min).

Helix → nucleus (2 m of DNA) → A·T·C·G (A–T, C–G) → helicase unzips (drop 1, a zap per pair) → polymerase adds the
matching letters (each letter is its note: A=E5, T=G5, C=B5, G=D6 — the sequence is the melody) → twist into two
helices, each 1 old + 1 new strand → proofreading (wrong letter removed and fixed) → thousands of forks (drop 2)
→ the cell divides → the left copy slides back into the opening helix (seamless loop).

Facts: ~3 billion base pairs per genome (~6 billion letters per cell); ~2 m of DNA per cell in a ~6 µm nucleus;
human polymerase ~50 nucleotides/s, thousands of origins at once, whole genome in ~8 h; ~1 error per billion after
proofreading; semi-conservative replication; the body makes ~330 billion new cells a day; DNA ~2 nm wide.
