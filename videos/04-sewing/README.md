# 004 · How does a sewing machine tie a knot it can't reach?

48 s · seamless loop · 9:16 · 60 fps · 120 BPM · cinematic pixel-3D. Build: `npm run video:sewing` (~4.5 min).

One stitch = one bar in slow-mo, with an event on every beat:
pierce (kick) → hook catches the loop (bell) → loop swings around the bobbin (swoosh) → take-up lever pulls it tight (snare).
Real speed is 16 stitches/s (960 per minute, "about 1,000"). 341 stitches in total, a whole number, so the loop closes.

Facts: lockstitch = upper thread loop carried around the bobbin by a rotary hook (2 turns per stitch), knot locked
inside the fabric; Elias Howe's lockstitch patent, 1846; lockstitch is the most common machine stitch.
